# Time to Show Up (TTSU)

Time to Show Up (TTSU) is a ground-up application designed to help peers turn what they say they will do into visible follow-through.

It is built as a multi-user platform from day one. Eli and Shawn are the initial acceptance testers, but they use the exact same authentication, onboarding, and application flows as any other user.
